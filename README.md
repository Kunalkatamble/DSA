# Array Operations in C

## Description

This project contains simple C programs that demonstrate basic operations on an array.

## Programs Included

1. **traversal.c** – Traverses the array and prints all elements.
2. **search.c** – Searches for a given value in the array and displays its position.
3. **sumofallelements.c** – Calculates and prints the sum of all array elements.
4. **max.c** – Finds and prints the maximum value in the array.
5. **min.c** – Finds and prints the minimum value in the array.
6. **insertatbeginning.c** – Inserts a value at the beginning of the array.
7. **insertatpos.c** – Inserts a value at a specified position by shifting elements.
8. **delete.c** – Demonstrates deletion of an array element.

## Concepts Used

* Arrays
* For loops
* If conditions
* Array indexing
* Searching
* Insertion
* Deletion
* Finding minimum and maximum values
* Finding the sum of elements

## How to Run

Compile any C file using:

```bash
gcc filename.c -o program
```

Then run:

```bash
./program
```

## Example

For the array:

```text
1 2 3 4 5
```

The programs can perform operations such as:

* Displaying all elements
* Searching for `3`
* Finding the sum: `15`
* Finding the maximum: `5`
* Finding the minimum: `1`
